Permanent project survey control

Download the 290 mm survey-control target

This three-file STL set creates one proposed high-contrast BOPRC permanent control plate. The files are separate so Bambu Studio can assign the correct colours to each component; they are normally loaded together and printed as one fused plate in one job.

Print in Bambu Studio

  1. In Bambu Studio, select all three STL files at once and choose Load as a single object with multiple parts. Do not auto-arrange the parts.
  2. Assign the structural base and dark inlays to black ASA, and assign the light inlays to white ASA.
  3. Print the combined model as one multi-colour job. The components fuse together during printing; they are not intended to be three loose field pieces.
  4. Confirm the assembled size is 290 × 290 × 3.2 mm and every fixing hole is open before slicing.
  5. Use ASA settings validated for the BOPRC printer, including suitable bed preparation, ventilation and warp control.
  6. Add the point ID and approved wording as contrasting surface text while keeping the surveyed centre unobstructed.
  7. Print a test piece before producing a full field set.
Approved wording:
BOPRC SURVEY CONTROL
PLEASE DO NOT REMOVE
0800 884 880

Field installation note

This STL set is a proposed fabrication starting point, not a certified installation design. Select fasteners and the installation method for the ground conditions and services. Install the plate nearly flush on a compacted fine-gravel pad, keep the exact centre visible, and survey that centre after installation.
