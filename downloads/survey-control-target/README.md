# BOPRC survey-control target - 290 mm print set

This multipart STL set creates a 290 x 290 mm high-contrast target for the Bambu Lab H2D-class build area. The plate has a 2.4 mm structural base, 0.8 mm top inlays, fixed raised lettering reaching 3.8 mm overall, and four 7 mm through-holes centred 15 mm from the corners.

## Print

1. Import all three STL files together as parts of one object. Do not auto-arrange the parts.
2. Assign the dark inlays to black ASA and the light inlays to white ASA. The base may use either approved ASA colour.
3. Confirm the assembled size is 290 x 290 mm, the plate body is 3.2 mm thick, the raised lettering reaches 3.8 mm, and every hole is open before slicing.
4. Use ASA settings validated for the BOPRC printer, with suitable bed preparation, ventilation and warp control.
5. The fixed wording (BOPRC SURVEY CONTROL / PLEASE DO NOT REMOVE / 0800 884 880) is built into the white inlay STL. Add only the unique point ID, such as GCP-001, in Bambu Studio as contrasting surface text, keeping the surveyed centre unobstructed.
6. Print a test piece before producing a full field set.

## Field note

The STL is a proposed fabrication starting point, not a certified installation design. Select fasteners and installation method for the ground conditions and services. Install nearly flush on a compacted fine-gravel pad, keep the exact centre visible, and survey that centre after installation.
